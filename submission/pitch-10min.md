# 10분 확장 발표 원고

8분 원고에 다음 두 구간을 추가한다.

## 6:30–7:30 위협 모델 상세

한 witness의 거짓말은 threshold를 만들지 못하고 한 개 중단은 허용하지만 두 개 중단은 fail-closed입니다. 반면 정상 witness quorum이 같은 잘못된 RPC를 읽거나 웹 배포와 trust bundle이 교체되는 공격은 보호 범위 밖입니다. 기관 승인 시스템과 gateway의 동시 침해도 잔여 위험입니다. 그래서 P0을 native QBFT light client라고 부르지 않습니다.

## 7:30–8:30 AI와 개인정보

위험 분석은 인증 여부를 바꾸지 않는 읽기 전용 내용 설명자로만 구현했습니다. 동의한 합성 전사문에서 송금·원격제어·인증번호·비밀 유지 요구를 설명하고 모델이 없으면 “규칙 기반 분석”이라고 표시합니다. localhost 전용 Ollama structured-output adapter는 있지만 이번 환경의 실제 모델 추론은 NOT-RUN입니다. 고객·연락 데이터는 온체인에 올리지 않고 SDP 원문도 로그에 저장하지 않습니다.

이후 도입·검증과 마무리를 각각 8:30–9:30, 9:30–10:00에 배치한다.
