# CallSign 기획제안서 11페이지 원고

1. **표지** — CallSign, “기관이 승인한 연락인지, 전화를 받는 순간 확인”, TEAM Signal, Web3 기반 사회문제 해결, 실제 LIVE 수신 화면.
2. **01 개요** — 기관 업무 시스템, 공동 인증망·연결 검증, 사용자 통화 화면. 발신 인증과 내용 위험 안내를 독립 표시.
3. **02 문제 정의·피해 현황** — 2025.10~2026.7 발생 12,554건·피해 6,324억 원. 전년 동기 대비 감소와 남은 판단 문제를 함께 제시.
4. **02 기존 대응** — 긴급차단, 에이닷 AI 경고, 문자 안심마크가 작동하는 범위와 통화별 기관 승인이 보완할 빈칸.
5. **03 차별성·기대효과** — SIP Identity·RCD·STIR 위임과 중복을 인정하고 개별 승인·전송 결합·공동 권한 통제를 결합.
6. **04 서비스 아키텍처** — 기관 승인 → 인증 API·1회 소비 → 게이트웨이 WebRTC → 사용자 검증. Besu와 위험 분석의 분리.
7. **05 핵심기술 스택** — 실제 React/Vite·Fastify·PostgreSQL·Solidity/Foundry·Besu QBFT·Ed25519/JCS·WebRTC·Ollama adapter.
8. **06 블록체인 적용** — 2-of-3 등록·복구, 4-node QBFT, 3-of-4 witness, on/off-chain 데이터 분리, 중앙 대안 인정.
9. **06 개발 일정** — 신청 9.14, 멘토링 9.19~11.5, 본선 11.6~7. 현재 구현과 후속 검증을 구분.
10. **07 팀 구성** — 양영우: 아키텍처·코어·보안. 이가은: UX·프론트엔드·데모. 사용자 제공 이력만 수록.
11. **08 개발증빙·레퍼런스** — 계약·프로토콜·DB·브라우저·QBFT/witness 실제 시험, 코드 경로, 피해 현황·선행사례·표준 출처, 선택 제출 GitHub 1건.

PPTX 생성 원본은 `scripts/generate-submission.ts`, 제출 파일은 `CallSign_기획제안서.pptx`와 같은 파일에서 변환한 PDF다.
