# CallSign 촬영 데모 현재 상태

- 접속: [업무 관리](https://callsign-rouge.vercel.app/demo/work) → [연락 검증](https://callsign-rouge.vercel.app/demo/call) → [공동 관리](https://callsign-rouge.vercel.app/demo/governance).

## 현재 되는 것

- 네 개 촬영 메뉴, 기존 검색·필터·업무 표·상세 drawer, 연락 3열·휴대폰, 공동 복구 단일 패널을 배포했다. 하단 Space/F 바는 제거했고 준비·기술 정보는 접었다.
- Space는 해당 역할의 실제 조작만 누른다. 버튼 포커스 뒤에도 동작하며 반복 입력은 막는다. F/Escape는 촬영 화면 표시만 바꾼다. 대상 외 영역 블러는 요소 자체에 적용하고 휴대폰 확대는 없앴다.
- 공동 복구 화면은 **현재 요청과 등록 승인키에 대해 검증한 공개 서명 두 개**가 준비된 경우에만 Space 한 번으로 A/B 확인 후 실제 복구 API를 제출한다. 서명키는 브라우저에 넣지 않는다. 원장 영수증과 서버 적용은 해당 응답으로만 표시하고, 명령별 Witness 증거는 현재 화면에서 `미관측`으로 남긴다.
- 기존 마이크→PBX/WebRTC→수신자 remote audio→동의→STT·분석 controller와 철회·종료 처리는 유지했다. 이번 배포에서 실제 통화나 유료 제공자 호출을 새로 실행하지 않았다.

## 현재 막힌 부분과 정확한 원인

- 06:00 KST 상담원 인증 세션의 `/api/v3/workspace` 응답은 위임 2건 모두 `revoked`, 유효한 진행 중 업무 0건이다. 그래서 `연락 준비`가 비활성이고 이번 변경으로 실제 마이크·통화·STT·분석 완료를 다시 검증할 수 없었다. 철회된 위임을 되살리거나 우회하지 않았다.
- 새 발신을 위해 기관 담당자가 **현재 승인된 실행 범위**에서 정상 위임을 발급·원장 등록하고 새 유효 업무를 배정해야 한다. 권한 변경의 현재 유효 승인 근거가 확인되지 않아 이 작업에서 제출하지 않았다.
- 공동 복구의 새 0/2→1/2→2/2→원장→적용 실제 실행도 기관이 현재 정지 상태가 아니고 새 동일 요청의 독립 서명이 준비되지 않아 미검증이다. 역사적 복구의 서버 적용 상태는 실제 응답으로 표시된다. Witness의 명령별 확정 근거는 관리 응답에 없어 별도 표시 완료로 주장하지 않는다.

## 촬영 시작

1. 노트북에 저장소 의존성과 Chromium이 설치된 상태에서, 권한 `0600`의 보호 계정 파일을 준비한다. `CALLSIGN_RECORDING_PREP_ENABLED=1 pnpm demo:prepare --credentials /보호된/계정.json`을 실행하고 **촬영 세션 준비**를 누른다. 기관·상담원·수신자는 서로 다른 Chromium 프로필 창을 사용한다.
2. 기관에서 유효 위임·업무를 준비한 뒤 다시 준비한다. 상담원·수신자에서 같은 업무를 선택하고 상담원 창에서 마이크를 선택·확인한다. 같은 노트북의 수신자 창은 이어폰으로 듣거나 출력 음소거해 피드백을 피한다.
3. `01 정상 연락`에서 연락 준비·발신, 수신자 수락과 동의를 진행한다. `02 위험 요구`에서는 상담원이 실제 마이크로 발언하고 수신자의 실제 전사·근거를 기다린다. `03 동의 철회`는 수신자가 직접 누른 뒤 일반 통화를 유지한다. `04 공동 복구`는 별도 승인된 정지·독립 서명 준비 후 기관 창에서 진행한다. Space는 준비된 현재 버튼만, F는 촬영 화면, Escape는 편집 화면으로 돌아간다.
4. 실패하면 화면의 실제 오류와 `업무·승인 상세`를 확인한다. 세션 만료 시 준비 화면에서 다시 준비한다. 실제 리허설과 녹화는 사용자가 한다.

## 기술 확인

- 로컬 웹 빌드·타입 검사, 소스 검사, 관련 5개 단위 테스트 통과. 인증 세션의 배포 화면을 1440×900·1920×1080·390×900에서 직접 캡처·열어 가로 넘침·휴대폰 잘림·하단 바 부재를 확인했다. 버튼 포커스 후 Space 1회 클릭과 F/Escape를 로컬 UI에서 확인했다.
- 이 확인은 UI와 현재 API 조회의 증거다. 정지 상태의 새 독립 서명 자동 실행, 실제 음성·STT·분석, 기관 정지·복구 권한 변경은 이번에 실행하지 않았다.
