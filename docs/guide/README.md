# CallSign 서비스 가이드

CallSign은 금융기관과 위탁 콜센터의 연락 업무를 고객의 통화 세션에 연결하는 서비스입니다. 기관이 정한 업무·수신자·목적을 바탕으로 발신 권한과 실제 연결을 확인하고, 동의한 상대 음성에서 위험 요구를 찾아 별도로 안내합니다.

## 서비스 흐름

기관 업무 생성·할당 → 콜센터 업무 위임 → 개별 연락 승인 → 수신자·현재 통화 검증 → 수락 후 통화 → 내용 위험 안내 → 별도 인증한 공식 후속 업무

기관의 연락 승인과 통화 내용의 위험은 서로 다른 판단입니다. 현재는 모의 금융기관의 이상거래 확인 업무로 개발하고 있습니다.
