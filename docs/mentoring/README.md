# CallSign 멘토링 검토 자료

## 이번 멘토링 질문

> 3차 멘토링 의견을 반영해 기관의 업무 위임, 개별 통화 승인, 실제 연결 검증과 AI 위험 안내 구조를 구체화했습니다. 이 서비스를 금융기관·위탁 콜센터에 실제로 적용한다고 보실 때, 도입을 가로막을 수 있는 가장 큰 문제와 이를 해결하기 위해 우선 보완해야 할 점은 무엇이라고 생각하시는지 의견을 부탁드립니다.
