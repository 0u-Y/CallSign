# 제출 문구 사실 확인

확인일: 2026-09-14. 외부 사실은 아래 원문과 대조했고, 구현 주장은 저장소의 실행 결과와 대조했다.

| 주장 | 판정 | 근거와 반영 |
|---|---|---|
| 2025.10~2026.7 보이스피싱 12,554건, 6,324억 원; 전년 동기 대비 39.9%·43.2% 감소 | 확인 | 관계부처 합동 2026.09.02 보도자료의 표 수치와 일치. 제안서 p3에 기간·비교 기준을 함께 표기. |
| 에이닷 전화가 통화 패턴을 분석해 팝업·소리·진동으로 단계별 경고 | 확인 | SKT 공식 보도자료의 기능 설명과 일치. 발신 기관 인증과 같은 기능처럼 쓰지 않음. |
| 안심마크가 공공·금융기관 문자 발신자의 기관명·로고를 표시 | 확인 | 연합뉴스 보도 내용과 일치. 전화의 통화별 승인 및 연결 검증과 구분. |
| 공식 일정: 접수 9.14, 멘토링 9.19~11.5, 본선 11.6~7 | 확인 | blockhack.kr 주요 일정 기준. 같은 페이지 안 발표 시간 표기가 8+2분과 10+5분으로 충돌해 8분·10분 원고를 모두 유지. |
| 서비스가 Next.js/FastAPI를 사용 | 정정 | 현재 코드는 React/Vite와 Fastify를 사용하므로 제출물은 실제 구현 스택으로 수정. |
| 공동 복구가 3-of-4 | 정정 | 계약의 중요 변경은 2-of-3 EIP-712 승인. 3-of-4는 별도 상태 witness 검증 문턱. |
| AI 모델 추론이 실행 완료 | 미주장 | 규칙 분석과 localhost Ollama adapter는 구현·시험했지만 이 환경에서 설치 모델 추론은 NOT-RUN. |
